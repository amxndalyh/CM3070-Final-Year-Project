# CM3070 Final Year Project

## Predictive Modelling of Social Media Trend Emergence

This repository contains the prototype notebook for my final-year project.

The prototype demonstrates the proposed data science pipeline for predicting social media trend emergence using simulated data.

### Notebook

- `trend_prediction_prototype.ipynb` — prototype implementation covering data generation, feature engineering, model training and evaluation.

### Data

The current prototype uses simulated data. Real social media data will be incorporated in the later stages of the project.

### Environment

The prototype was developed using Python and Jupyter Notebook through Anaconda.
